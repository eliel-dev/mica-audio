# Handoff - HUB75 128x64 hard cutover

## Escopo classificado

Mudanca estrutural de firmware, protocolo, simulador, preview HUB75 local e catalogo ativo.

## Objetivo

Consolidar a base no painel `hub75_p2_5_128x64_smd2121_scan32`, removendo `64x32` do fluxo ativo.

## Arquivos alterados

- `src/MicaAudio.Core/Led/LedDefaults.cs`
- `src/MicaAudio.Core/Led/LedPayload.cs`
- `src/Device.Protocol/Stream/StreamFrameV2.cs`
- `src/Output/Led/MatrixPortalLedOutput.cs`
- `src/Output/Led/SimulatorLedOutput.cs`
- `src/App.WinUI/Services/AudioPipelineCoordinator.cs`
- `src/App.WinUI/Services/Firmware/PrecompiledFirmwareService.cs`
- `firmware/matrixportal-s3/platformio.ini`
- `firmware/matrixportal-s3/src/main.cpp`

## Decisoes tomadas

1. `LedDefaults` migrou para `128x64`.
2. `LedPayload` migrou para `Bins128` e `Frame128x64`, mantendo aliases legados temporarios.
3. `StreamFrameV2` virou o contrato binario ativo.
4. O catalogo oficial ficou restrito a DevKitC-1 `stable` e `dma_exp`.
5. O preview HUB75 do Visualizador foi simplificado para um unico canvas nativo `128x64`.
