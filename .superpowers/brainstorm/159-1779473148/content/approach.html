Como construir o editor de watchfaces?

Escolha a abordagem que melhor se encaixa no seu fluxo de trabalho

🌐
Arquivo HTML único
Abre no browser, sem instalar nada

A — Web Standalone

Um único watchface-editor.html que você abre direto no Chrome. Canvas 128×64 simulando a matriz LED, controles de parâmetros, e botão "Exportar JSON". Sem servidor, sem dependências.

Vantagens

  • Zero setup
  • Funciona offline
  • Fácil de compartilhar

Limitações

  • Preview estático (sem animação real do C#)
  • Exporta JSON, você aplica manualmente
🔄
Web + Hot Reload
Editor web conversa com o app C#

B — Editor com Live Preview

Editor web local que salva um watchface-params.json monitorado pelo app WinUI. O app recarrega os parâmetros em tempo real e você vê a animação de verdade (C# / Win2D) enquanto ajusta os sliders.

Vantagens

  • Preview real (animação C# idêntica)
  • Fluxo contínuo: ajuste → veja na hora

Limitações

  • Precisa de pequena mudança no app C#
  • App precisa estar aberto ao lado
🖥️
Reimplementação em JS
Porta o render C# para JavaScript

C — Canvas JS Animado

Reimplementa o render de cada watchface em JavaScript (Canvas API). Editor web completo com animações reais rodando no browser, sem precisar do app C# aberto. Exporta parâmetros para aplicar no C#.

Vantagens

  • Animação real no browser
  • Completamente independente

Limitações

  • Maior esforço inicial (portar 10 watchfaces)
  • Risk de divergência C# ↔ JS
