Como o editor envia parâmetros para o app?

Escolha como a comunicação entre o browser e o WinUI vai funcionar

Browser ──── HTTP PUT ────▶ C# App
slider muda → fetch() imediato → frame seguinte já usa o novo parâmetro
latência: <5ms

A — HTTP endpoint (Recomendado)

Adiciona um endpoint PUT /api/watchface-params/{nome} ao servidor existente do app. O editor web faz fetch() a cada mudança de slider. O app aplica os novos parâmetros no próximo frame de render — sem arquivo, sem polling.

Vantagens

  • Instantâneo (<5ms)
  • Sem escrita em disco
  • Fácil de expandir

Limitações

  • Adiciona ~20 linhas ao servidor C#
Browser ──▶ JSON ──▶ FileSystemWatcher ──▶ C# App
slider muda → salva arquivo → watcher detecta → reload → frame usa novo parâmetro
latência: ~50-200ms

B — FileSystemWatcher + JSON

O editor salva watchface-params.json em disco (via File System Access API do browser). O C# usa FileSystemWatcher para detectar mudanças e recarregar os parâmetros automaticamente.

Vantagens

  • Arquivo editável manualmente
  • Sem mudança no servidor HTTP

Limitações

  • Latência de 50-200ms
  • Requer permissão de arquivo no browser
